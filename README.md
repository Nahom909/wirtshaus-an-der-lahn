# Wirtshaus an der Lahn, Wetzlar

Vorschau-Website: `index.html` (Startseite), `events.html` (Unterseite Events), gemeinsames `style.css`, Bilder in `images/`.

- Fotos stammen aus dem Google-Maps-Profil des Betriebs. Das Plakat auf der Events-Seite ist das Würfelturnier-Plakat des Betriebs.
- Speisekarte mit allen Preisen laut den Karten des Betriebs; E-Mail und Impressum sind Platzhalter.
- Keine Rezensionen, keine Embeds, keine Cookies. Einzige Fremdverbindung: Google Fonts.
